# Gruppenstempel in Liste und Karten-Bottomsheet

Die Screenshots zeigen die lokal gestartete Expo-Web-App in einer mobilen
Browseransicht mit 390 × 844 CSS-Pixeln (Pixelverhältnis 2).
Die OData-Antworten wurden ausschließlich im Screenshot-Browser durch Demo-Daten
ersetzt: Max Wanderer und Anna Adler haben das Brockenhaus besucht, Ben Berg noch
nicht. Die Profilbilder fehlen bewusst, sodass die Initialen-Avatare sichtbar sind.
Es wurden keine Besuche oder Freundschaften im Backend angelegt.

- `list.png`: dieselbe gemeinsame Komponente in der Stempelstellenliste.
- `map-expanded.png`: Karten-Bottomsheet mit Gruppenzähler, Avataren und Aktionen.
- `map-compact.png`: Gruppenzähler und Avatare bleiben nach Verschieben der Karte sichtbar.
