# Abzeichenalbum – tatsächliche UI

Aufgenommen am 15. Oktober 2026 im lokalen Basic-Auth-Testbetrieb. Separater
CAP-Server auf Port 4014 und statischer Webexport auf Port 8084, Chrome Headless.
Keine Produktionsdaten wurden geändert. Die Demofigur „Mara (Demo)“ verwendet
58 reguläre Stempelstellen (Nummern 1–58); für die zusätzlichen Themenrahmen-
Aufnahmen wurden auch deren Pflichtstellen und drei Sonderstellen besucht.
Die Besuchsdaten sind Testdaten. Alle Aufnahmen wurden nach dem Review neu erstellt.

Der Browser-Smoke-Test prüfte Anmeldung, leeres/gemischtes Album, Details,
unabhängige Auswahl, gespeicherte Auswahl, zentrale Profilanpassung, Name-/Bild-Editor,
alle drei Themenrahmen am Avatar, Zielfilter/Reset sowie
Offlinecache und gesperrtes Offline-Speichern. Auf dem kleinen Display wurden
zusätzlich die sichtbare Position des Speichern-Buttons und horizontaler
Überlauf geprüft. Die Aufnahmen sind Webtests; native Gerätetests ersetzen sie nicht.
