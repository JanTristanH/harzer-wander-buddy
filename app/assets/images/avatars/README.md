# Standard-Avatare

`bear.png`, `fox.png` und `lynx.png` sind eigene, mit dem eingebauten Imagegen-Tool generierte Illustrationen für das Onboarding. Die Ausgaben wurden auf 512 × 512 Pixel verkleinert. Die vierte Auswahl „Kein Avatar“ verwendet das bestehende User-Icon.

## Generierungs-Prompt

Ein separater Aufruf je Tier; `{animal}` war `bear`, `fox` beziehungsweise `lynx`. Kein Referenzbild, kein transparenter Hintergrund.
